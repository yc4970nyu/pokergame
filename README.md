# 大老二

2–3 人联机扑克牌游戏。React + TypeScript 前端，Node + Socket.IO 服务器，规则引擎前后端共用。

## 本地运行

```bash
npm install
npm run dev        # 服务器 :3001 + 前端 :5173
```

打开 http://localhost:5173 。手机和电脑在同一个 Wi-Fi 下，手机打开 `http://<电脑IP>:5173` 就能一起玩。

其他命令：

```bash
npm test           # 规则单元测试（含 300 局机器人对战）
npm run build      # 打包前端到 client/dist
npm start          # 生产模式：一个进程同时提供网页和联机服务（默认端口 3001，可用 PORT 改）
```

## 上线

任何能跑 Node 20+ 并支持 WebSocket 的平台都行（Render、Railway、Fly.io、自己的服务器）：

```bash
npm install && npm run build
npm start
```

或者用 Docker：`docker build -t dalaoer . && docker run -p 3001:3001 dalaoer`

房间数据存在内存里，服务器重启会清空正在进行的牌局。只需要跑一个实例。

## 规则（引擎里实际实现的）

- 一副牌 52 张，不要大小王。
- 点数：3 < 4 < … < K < A < 2。花色：♣ < ♦ < ♥ < ♠。
- 发牌：先随机翻出一张牌，剩下的每人发 17 张。翻出的牌给拿到最小牌（通常是 ♣3）的人，他先出。如果翻出来的就是 ♣3，就给手里最小牌的人。
- 两人局：每人 17 张，其余 17 张不用。
- 牌型：单张、对子、葫芦（三带二）、顺子（5 张）。
  - 对子：先比点数，同点比大的那张的花色。
  - 葫芦：只比三张的点数。
  - 顺子：A2345 最小，然后 34567 … 10JQKA，23456 最大。不能绕（JQKA2 不算）。同样的顺子比最大那张牌的花色（23456 和 A2345 看 2 的花色）。
- 炸弹：铁支（四张一样 + 一张单牌）、同花顺。任何时候都能出，压任何牌型。同花顺 > 铁支，同类炸弹比大小。
- 一轮内只能出同一种牌型（或炸弹）。说了"不要"就不能再出，直到这一轮结束。其他人都不要，最后出牌的人重新开始。
- 计分：先出完的人赢，加上另外几家手里剩的牌数。输家扣自己剩的牌数（零和）。只想让赢家加分的话，把 `shared/src/game.ts` 里的 `losersLosePoints` 改成 `false`。

## 视觉

浅色磨砂玻璃桌面 + 金色点缀，深墨蓝金边牌背。颜色都在 `client/src/styles.css` 顶部的变量里。
动画用 Motion 的弹簧：发牌从牌堆飞向各座位、选中上浮发金光、出牌弧线飞到桌面落地回弹、对手的牌空中翻面、结算时筹码飞向赢家。右上角设置可调动画速度或关闭。

## 代码结构

```
shared/src/      规则引擎（前后端共用）
  cards.ts       牌的编号：id = 点数序号*4 + 花色序号，直接比 id 就是比单张大小
  combos.ts      牌型识别、比大小、枚举可出的牌（提示和机器人用）
  game.ts        发牌、出牌、不要、回合、计分（纯函数）
  bot.ts         机器人
  protocol.ts    前后端消息类型
server/src/      Socket.IO 服务器：房间、断线重连、机器人托管
client/src/      React 前端
client/public/cards/   牌面：svg-cards.svg（htdebeer/SVG-cards，LGPL，见 LICENSE-svg-cards）。同目录的 PNG 是旧版本用的，现在没用到，可以删。
                       牌背是自己设计的，在 client/src/Card.tsx 的 CardDefs 里。
scripts/         开发用：无头浏览器截图 / 自动打一局
```

## 联机细节

- 每个浏览器有一个固定的玩家 token（存在 localStorage），刷新或断网后会自动回到原来的座位。
- 断线的人轮到出牌时，20 秒后由机器人代打。
- 游戏中主动离开房间，座位交给机器人托管。
- 房主可以加机器人、踢人、切换 2/3 人局。

## 操作

- 点牌选中。手机上手指快速划过多张牌可以连选。
- 理牌：手机上按住一张牌（约 0.3 秒）拿起来，拖到想要的位置；电脑上直接拖。默认按大小排，「按大小 / 按花色」随时一键重排。
- 提示：每按一次换下一个能出的组合。
- 电脑键盘：Enter 出牌，P 不要，H 提示，Esc 取消选择，Shift+←/→ 移动当前牌。
- 右上角设置：动画速度（正常/快速/关闭）、音效开关。
